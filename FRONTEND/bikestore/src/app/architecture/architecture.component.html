System Architecture & Design

Project Overview

This project was developed as a university assignment with the primary goal of mastering the N-tier (Layered) Architecture pattern using modern web technologies. The focus was not just on building a functional bike store, but on creating a scalable, maintainable, and decoupled backend system.

Backend Layering

1. Endpoint Layer (API)

ASP.NET Core Web API controllers. Handles HTTP requests, input validation, and routing. Decoupled from logic via Dependency Injection.

2. Logic Layer (Services)

The "Brain" of the system. Contains business rules, complex calculations (like average price), and orchestrates data flow.

3. Data Layer (Repository)

Entity Framework Core implementation. Manages database context, migrations, and CRUD operations against SQL Server.

4. Entities Layer

Plain Old CLR Objects (POCOs) representing the data models. Shared across all layers to maintain structural integrity.

Tech Stack

ASP.NET Core 8.0 Entity Framework Core SQL Server Angular 19 TypeScript Bootstrap 5 SCSS

Key Learnings

  • Implementation of the Dependency Injection pattern to ensure decoupling between layers.
  • Handling One-to-Many relationships in EF Core and reflecting them in the UI.
  • Creating a Responsive Single Page Application (SPA) that provides a desktop-like experience.
  • Simulating complex backend behavior in a static environment (Demo Mode) using Angular Interceptors.
